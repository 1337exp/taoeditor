# Changelog

## 0.2.0

- **Superscript and subscript.** Two new marks, `superscript` and `subscript` (Ctrl+. and Ctrl+, as in Docs, buttons in the toolbar, `<sup>` and `<sub>` in the viewer). They exclude each other (one replaces the other; if a stored document has both, superscript stays) and `code`; pasted `sup`, `sub` and `vertical-align` from Docs and Word are read. New labels `superscript` and `subscript` in `TaoEditorLabels`.
- **The ready profiles are leaner**: `comment` has the bar of Reddit (bold, italic, strikethrough, superscript, size, link, lists, spoiler, quote, code, code block, table) and no text and background colour, underline, subscript, alignment or indents (lists are nested with Tab); `chat` also has no superscript; `article` keeps everything. The code block button stands next to the inline code one. A project can still take marks away or define its own profile (`defineProfile` with the marks it wants).
- **One row toolbar.** The toolbar uses TaoUI 5.31 `overflow`: it stays one row, and the groups that do not fit go under a "More" button (the history group stays). The popups of a button in that panel open below the panel. New label `more`. `@1337exp/taoui` is now `^5.31.0` (peer and dev); `floating` toolbars are not changed.
- **Code block button.** The code block (a block of plain monospaced text, apart from the inline `code` mark) gets a toolbar toggle: the selected lines become one block (text only: marks go, a mention becomes its `@name`) and back to a paragraph. Enter or Shift+Enter on an empty last line leaves the block, so one at the end of the document has a way out. `createEditor` gains `toggleCodeBlock`; new label `codeBlock`. A table cell does not take one.
- **Tables.** New nodes `table`, `tableRow`, `tableCell` and `tableHeader` in the document (`comment` and `article` have them, `chat` does not; `withoutFeatures(profile, { nodes: ['table'] })` takes the table and its parts away together). A table is a plain rectangle: the normalizer fills a short row with empty cells, cuts it to 50 rows by 20 columns, and keeps tables out of cells, quotes and lists; merged cells and column widths are not in the model. A profile without tables shows the cells as paragraphs.
- **In the editor** (on `prosemirror-tables` 1.8.5, exact): a table button with a size picker (8 by 6, arrows walk it), and, when the caret is in a table, a menu for rows, columns, the header row and deleting the table. A small button on the cell with the caret opens the same menu next to it (a long table needs no trip to the toolbar). Tab and Shift+Tab walk the cells and fall through at the ends; while editing, a table at the start or the end of the document has an empty guard paragraph next to it so the caret can stand there (easy on a phone); the guard paragraphs are not part of the document: `getDoc`, `change` and `send` leave out one empty paragraph before a first table and one after a last table. `createEditor` gains `insertTable`, `inTable`, `tableCommand`, `canTableCommand`. Pasted tables (Google Docs, Excel, web pages) are read through the schema; in a profile without tables a space is kept between the cells.
- **Paste without formatting**: Ctrl+Shift+V pastes only the text of the clipboard (the engine does this itself; a test now guards it). No toolbar button, on purpose: Gmail and Docs have none, and a phone has no such keys.
- **Viewer and server**: `TaoEditorView` and `toHtml` render `<table>` with `th` and `td`; the look is in `content.css`.
- New labels in `TaoEditorLabels` (`table`, `tableGrid`, `tableRowAbove`, `tableRowBelow`, `tableRowDelete`, `tableColumnBefore`, `tableColumnAfter`, `tableColumnDelete`, `tableHeaderRow`, `tableDelete`): an app that passes a complete `labels` object has to add them.

## 0.1.0

The first release.

- **A document of our own.** A versioned JSON tree (`{ v: 1, content: [...] }`) is the only thing that is stored. A normalizer is the gate for everything that comes in or goes out: it never throws, strips what the profile does not allow, and keeps the text of what it unwraps. Links go through one allowlist (`https`, `http`, no credentials).
- **Profiles.** Ready `chat`, `comment`, `article`; `withoutFeatures(...)` and `defineProfile(...)` make your own. What a profile leaves out is gone everywhere at once: the toolbar button, the hotkey, pasted formatting (it comes in as plain text) and a stored document shown with that profile. A typo in a name throws.
- **The marks and blocks.** Bold, italic, underline, strikethrough, code, spoiler, link, text size (small, large, huge), text colour and background colour (stored as `#rrggbb`); paragraphs, headings 1 to 3, quote, code block, bulleted and numbered lists; indent (0 to 8) and alignment as attributes of a line; hard break; mentions (`@name`, an `id` and a label).
- **Nothing is converted behind your back.** There is no Markdown input: what is typed or pasted stays what it was. Pasted HTML is read only through the schema's rules (Google Docs, Word and Gmail runs included, minus the black ink and white paper they put on everything); scripts, handlers, images and unsafe links cannot get in.
- **`TaoEditor`** (`@1337exp/taoeditor/vue/taoui`), built from TaoUI components: `v-model`, `change`, `send`; a toolbar in the order of a mail client (fixed, or `floating` over the selection) that shows only what the profile has; popups for colours, alignment, size and paragraph style; a link form that refuses unsafe URLs; mentions through a `mentions` function of the app (with a list that works with keys, mouse and screen readers); an emoji button (plain Unicode text); `spaced` (a gap between paragraphs or none); `readonly`, `disabled`, translatable `labels`.
- **`TaoEditorView`** (`@1337exp/taoeditor/vue`): a viewer that never loads the editing engine; spoilers open on click, mentions are buttons when the app listens. `toHtml` / `toRenderTree` render the same document on a server (no DOM, safe by construction).
- **The editing engine** (`@1337exp/taoeditor/editor`): `createEditor()` on seven small ProseMirror packages, exact versions; the keys of Gmail and Docs; Enter or Ctrl+Enter sends and an IME composition never does.
- **Made for TaoUI, usable without it.** The look comes from `--te-*` variables with neutral defaults; `taoui.css` points them at the TaoUI tokens, `class="tao-prose"` hands the typography to TaoUI. Only `src/vue/taoui/` imports TaoUI, and `taoui.css` is the only file that names its tokens (tests guard both, and check that every token exists in the installed TaoUI).

Not checked yet: IME on Android and iOS and Japanese or Korean composition, touch devices, Firefox and Safari. Imports are by subpath (there is no root entry); `vue` and `@1337exp/taoui` are optional peer dependencies.
