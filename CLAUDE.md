# TaoEditor

Перед работой прочитать `E:\job\base\README.md` (таблица «если упомянуто X, читать Y») и `docs/architecture.ru.md` этого проекта: решения, что доказано, что нет.

- Стек и правила: Vue 3 + Vite + TS, ядро без DOM (`src/core`), UI на TaoUI, тесты на ядро; см. `E:\job\base\conventions.md`.
- Хранится только наше дерево (`src/core/model.ts`). HTML не хранить, JSON ProseMirror форматом не делать. Всё, что входит и выходит, проходит `normalizeDoc`.
- Слои (`tests/layers.test.ts`): `core` ничего не импортирует, `editor` только движок и ядро, `vue` Vue, ядро и редактор; TaoUI только в `src/vue/taoui/`. В `src` нет `innerHTML`/`eval`. Вид только через переменные `--te-*`, мост к TaoUI в `src/styles/taoui.css`.
- ProseMirror закреплён точными версиями (без `^`). Новые чужие зависимости не добавлять без причины.
- Перед «готово»: `npm run typecheck`, `npm test`, `npm run build`, для защит ещё `npm run mutate` (все мутанты должны быть пойманы), для интерфейса посмотреть `/lab/` в браузере.
- Пока не проверено: IME на устройствах, Firefox/Safari. Не писать «работает», не указав это.
- **Экранирование ломает правки** (2026-11-07, дважды): `node -e '...'` в bash и инструменты Write/Edit съедают или разворачивают обратные слэши (`\w` стало `w`, `\x00` стало байтом NUL, `\u0020` пробелом, `\n` переводом строки). Скрипты правок класть **файлом** в папку сессии (`scratchpad`) и запускать `node файл`; регулярки с `\` проверять `grep`, а после правки гонять тесты и искать сырые управляющие символы.
- После обновления зависимости перезапускать dev-сервер и чистить `node_modules/.vite` (иначе браузер показывает старую версию, а тесты зелёные). Интерфейс на TaoUI сверять с руководством: `E:jobgit	aouiskills	aouieferencespatterns.md`.
- Размер панели и эмодзи в `TaoEditor`: обычный (medium), решение пользователя; руководство TaoUI советует `small` для панелей инструментов, здесь сознательно не следуем. Не возвращать `small` по умолчанию.
- Мост к TaoUI: `--tao-*` называются только в `src/styles/taoui.css` (тест `tests/bridge.test.ts`); новая цветовая, радиусная, шрифтовая или теневая переменная `--te-*` сразу получает строку в мосте.
- Перехват Tab: только там, где у клавиатуры остаётся выход (см. `docs/architecture.ru.md`).
- `demo/` это страница-витрина (`npm run demo`, порт 5197), в пакет не входит. Новую возможность редактора показывать и в демо (раздел «Возможности» берёт имена из ядра), тексты демо на двух языках (`demo/src/locales`).
